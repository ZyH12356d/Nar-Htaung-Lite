# Nar Htaung Lite branding

The original mark combines a flowing N-shaped audio waveform with rounded sound bars,
in mint on charcoal. It was generated and refined with the built-in image_gen tool.
The selected final artwork is an opaque 1254 × 1254 PNG, with room for circular icon masks.

The original generated raster artwork is retained in:

- `Resources/AppIcon/appicon.png`: original generated artwork, retained as a brand reference.
- `Resources/Splash/launch_logo.png`: native startup splash, with charcoal background.
- `wwwroot/logo/nar-htaung.png`: opening loader and app header.

The phone launcher uses separate native vector layers: `appicon.svg` is the solid charcoal
background; `appiconfg.svg` is the transparent mint waveform symbol. MAUI applies a foreground
scale of 0.55 so the symbol has breathing room inside circular and rounded launcher masks.
The transparent foreground also supplies a recognizable glyph for Android themed icons.
The splash, opening loader, and header continue to use the approved generated raster artwork.

## Original generation prompt

Use case: logo-brand.
Asset type: production foreground logo for an Android music app launcher icon and splash screen, square 1024 x 1024 PNG with a genuinely transparent background.
Primary request: create one original, polished, memorable music-listening symbol for Nar Htaung Lite. Build a bold abstract lowercase n from a smooth flowing audio waveform, with rounded vertical ends and one simple curved connecting stroke. Integrate two short rounded sound bars just beside the main form so it reads immediately as music and listening. Keep the silhouette cohesive, balanced and recognizable at 24 pixels.
Style: flat vector-like graphic, exceptionally clean rounded geometry, consistent thick strokes, warm and calm, understated premium music app.
Color palette: solid pale mint green #C3EDB5; the symbol is designed to sit on charcoal #101514 but the actual background must be fully transparent.
Composition: one centered standalone symbol, approximately 72% of the canvas width and height, generous even transparent margins, no clipping. No app tile or bounding square.
Text: none.
Avoid: letters as typography, words, .NET branding, blue or purple, headphones clip art, thin details, gradients, shadows, glow, 3D, mockups, presentation boards, multiple options, watermarks.

## Final selected artwork prompt

The generated original mark was supplied as the edit reference.

Create the final Android launcher icon from this reference mark. Preserve the exact recognizable concept: a bold flowing N-shaped audio waveform with one short rounded vertical sound bar on each side. Render it afresh as a pristine flat vector-style icon: pure solid pale mint #C3EDB5 glyph, immaculate smooth edges, absolutely no texture, grain, artifacts or white pixels anywhere.
Fill the entire square canvas edge-to-edge with one perfectly uniform solid charcoal color #101514, including every gap inside the glyph. This is an OPAQUE app icon, no transparency, no rounded outer corners, no separate tile, no border, no lighting, no gradients, no shadow.
Center the mint symbol with even generous margins. It should occupy about 65% of the square's width and 50% of its height, leaving ample safe space for circular launcher masks. The only visible content is the mint symbol on the solid charcoal field. No text, no watermark, no mockup. Export square PNG.
